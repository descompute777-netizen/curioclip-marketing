## Análisis FASE 3 — Patrones de Estructura Ganadora

### Patrón 1: REVELACIÓN INVERSORA (aparece en 18/42 outliers) ⭐⭐⭐
```
HOOK LITERAL: "Lo que crees que sabes es mentira / NO es lo que parece"
ESTRUCTURA: Asunción falsa → contradicción inmediata → datos/demostración
EJEMPLO: "Tu memoria NO recuerda nada hasta que lo haces"
POR QUÉ: Genera DISONANCIA COGNITIVA + impulso inmediato a ver completoOBLIGATORIO)
```
**Outliers con este patrón:** #1, #3, #5, #8, #11, #15 (6.2x promedio)

### Patrón 2: RELATIVIDAD COTIDIANA (16/42 outliers) ⭐⭐
```
HOOK LITERAL: "Hiciste [acción cotidiana] más rápido/fuerte/loco que [referencia ÉPICA]"
ESTRUCTURA: Cotidianidad → reencuadre con referencia de escala → validación datos
EJEMPLO: "Viajaste más rápido hoy que un astronauta en el espacio"
POR QUÉ: Transforma lo mundano en ASOMBROSO sin parecer exagerado
```
**Outliers con este patrón:** #2, #5, #7 (6.9x promedio)

### Patrón 3: DECODIFICACIÓN DE MISTERIO (12/42 outliers) ⭐
```
HOOK LITERAL: "Nadie sabe [X] / [X] está escondido / [X] es un [sorpresa]"
ESTRUCTURA: Misterio planteado → desarrollo lógico → revelación final
EJEMPLO: "Nadie sabe dónde está el 95% del universo"
POR QUÉ: Genera URGENCIA por respuesta, curiosidad activa
```
**Outliers con este patrón:** #4, #6, #13 (6.3x promedio)

### Patrón 4: AUTORIDAD CORPORAL / BIOLÓGICA (14/42 outliers)
```

ESTRUCTURA: Corporalidad → despropiación emocional → datos científicos
```
